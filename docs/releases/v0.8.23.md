# v0.8.23

This release carries everything in v0.8.22 and moves gorilla/websocket to the commit that fixes GO-2026-6278. v0.8.22 was tagged and published to npm, and its GitHub Release never went out: govulncheck flagged the advisory on the tag, and the release stopped there. Use v0.8.23.

## Security

- **gorilla/websocket moves to `v1.5.4-0.20240701034025-d67f41855da4` across every module.** v1.5.3 draws the client's mask key from a weak PRNG (GO-2026-6278), and `massrelay.Dial` reaches it. The fix commit requires `golang.org/x/net`, which 27 modules now list as an indirect requirement. (PR 1759)

## Also in this release, from v0.8.22

### Added

- **Server Cards.** `server.WithServerCard` serves a SEP-2127 v1 card at `<prefix>/server-card`. It builds the card from the server's `Implementation` and the versions its endpoint accepts. `srv.SetCardExtensionInfo(id, fn)` lets an extension add its own `extensionsInfo` entry, and `core` gains the card types and `Validate`. (PR 1739)
- **Signed webhook deliveries.** `events.WithWebhookSigningKeys` adds an ed25519 `v1a` signature to each delivery, beside the `v1` HMAC. `VerifyServerIdentity` checks one on the receiving side. (PR 1741)
- **Signing keys on the card.** `events.Register` publishes the keys on the Server Card. `client.FetchServerCard` and `ServerCardCache` read a server's card from its own origin, and `eventsclient.WithServerIdentity` accepts a delivery only when a key on that card signed it. (PR 1743)
- **Groups prototype.** `experimental/ext/groups` serves `groups/list` and `groups/get` from the WG draft. `server.SetListScope` lets an extension hide primitives from one caller's list results, and `testconf-groups` runs the scenario on both wires. (PRs 1709, 1727)
- **Browser playgrounds.** The docs site publishes runnable examples under `/try/`, including getting-started running in the browser through wasm. Each playground has a stateless and session wire switch and a collapsible wire log. (PRs 1713, 1715, 1717, 1720, 1721, 1722, 1725, 1730)
- **`examples/disclosure`** and `make exercise-disclosure`. (PR 1706)

### Changed

- **A room bridge refusal says whose page refused.** A call on another person's page says they have not paired with you, and how they can. A call on your own page with its switch off says to turn the switch on. A call that names no page says the same about the pages that offer the tool. A client that matched the old text "has not agreed to you" needs the new text. (PR 1757)
- **Go 1.26.11 is the floor across all modules.** (PR 1748)
- **servicekit v0.2.5 and oneauth v0.3.19 across every module.** (PRs 1740, 1751)
- **The GitHub Release is created only after the tag's workflows pass and every command installs.** (PR 1697)

### Fixed

- **A `skills/list` entry with an invalid `resources` value no longer fails the whole listing.** The entry decodes with no resources, and `ReadFromEntry` refuses it with `ErrInvalidResources`. 13 more SEP-2640 rows are graded. (PR 1728)
- **A race between a tool-call stream and the event store's trim is gone.** (PR 1698)
- **Code blocks on the docs site follow dark mode.** (PR 1724)

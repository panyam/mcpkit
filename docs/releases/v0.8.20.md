# v0.8.20

A small patch release that clears the code scanning alerts from the last batch of merges. No
library API changes.

## Changed

- **CI jobs read the repository only.** `test.yml` grants `contents: read` at the top level instead
  of the repository's default token. The two jobs that post reports keep their own job-level
  permissions. (PR 1689)

## Examples

- **Lanternfall's sign-in cookie sets `Secure` whenever the request came over https.** Plain http
  on localhost keeps working, where some browsers drop a `Secure` cookie. (PR 1689)

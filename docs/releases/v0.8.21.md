# v0.8.21

A patch release. It fixes a flaky room join in `experimental/ext/rooms/massrelay`, tags
`experimental/ext/protogen` again, and adds CI that builds every tagged module and runs the example
tests. No library API changes.

## Fixed

- **A dialled room join no longer fails when room traffic arrives before its answer.** The relay
  adds a joining client to the room and starts forwarding the room's events before it writes the
  join's `RoomJoined`, so a `PeerJoined` or an addressed message could reach the socket first.
  `massrelay.Dial`'s `Join` failed with "unexpected answer" when that happened. It now holds those
  events and replays them into the member once the join completes. (PR 1696)

## Changed

- **`experimental/ext/protogen` is tagged with every release again.** Its last tag was v0.2.47, which
  pinned mcpkit v0.2.3. From this release `go install
  github.com/panyam/mcpkit/experimental/ext/protogen/cmd/protoc-gen-go-mcp@v0.8.21` resolves against
  this release's root. (PR 1693)
- **CI builds, vets and tests every tagged module against main.** Eleven tagged modules had no job
  that compiled their own packages or tests. (PR 1694)
- **CI runs the example tests.** Nothing in CI ran `make test-examples` before, so an example whose
  tests broke could merge green. (PR 1692)
- **`make testall`'s protogen stage fails when generation fails**, rather than reporting a pass and
  leaving the generated directory deleted. (PR 1695)
- **The conformance report is regenerated against upstream c37eec8.** No graded result changed.
  (PR 1691)

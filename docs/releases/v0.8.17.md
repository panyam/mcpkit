# v0.8.17

A patch release that tightens the wire on both transports and lets chakra adopt the agents
extension's declare rule. A server now refuses `agents/list` and `agents/get` from a client that
didn't declare the extension, and Go clients declare it with `agentsclient.WithExtension()`. The
four base list methods page at 250 by default, the stateless wire requires `MCP-Protocol-Version`,
and `tools/call` checks `Mcp-Param-*` headers against the body.

## Upgrade notes

- **Go clients of the agents extension add `agentsclient.WithExtension()`**, or `agents/list` and
  `agents/get` fail with `-32021`. (PR 1674)
- **A client that ignores `nextCursor` sees only the first 250 tools, resources, templates or
  prompts.** mcpkit's own `List*` helpers follow cursors. `server.WithDefaultPageSize(0)` restores
  single-page lists. (PR 1663)
- **Hand-built stateless requests send `MCP-Protocol-Version`.** The mcpkit client already does.
  (PR 1663)
- **A skill that relied on serving a dotfile** needs `WithHiddenFiles()`. (PR 1666)

## Added

- **`agentsclient.WithExtension()`** declares `io.modelcontextprotocol/agents` on a Go client.
  (PR 1674)
- **The server checks `Mcp-Param-{Name}` headers on `tools/call`.** For each argument a tool's
  schema marks with `x-mcp-header`, the header must mirror the body after Base64 decoding. A
  missing, mismatched or badly encoded header gets HTTP 400 and `-32020`, on both wires. A required
  `x-mcp-header` argument missing from the body is `-32020` too. (PR 1668)
- **`core.CreateTaskResult` and `core.DetailedTask` keep extension fields** in a new
  `Extras map[string]any`. A Go client used to drop keys such as `eventSource`. (PR 1670)

## Changed

- **`agents/list` and `agents/get` refuse an undeclared client** with `-32021` and the missing
  capability in `data`, HTTP 400 on the stateless wire. The check runs before step-up, so an
  undeclared client never sees a 403 naming an agent's scopes. (PR 1674)
- **The base list methods page at 250 items by default**, on both wires, and an invalid cursor is
  `-32602`. (PR 1663)
- **The stateless wire requires `MCP-Protocol-Version`**, and `subscriptions/listen` checks
  `Mcp-Method` like the other stateless entry points. (PR 1663)
- **`core.DecodeMcpHeaderValue` reads `=?base64?` without the closing `?=` as a literal**, as the
  SEP-2243 test-case table says. (PR 1668)
- **`ext/skills` skips hidden files and directories by default**, so a skill's `.env` or `.git/`
  is no longer served or packed. `WithHiddenFiles()` turns the filter off. (PR 1666)
- **Events webhooks mint a `webhook-id` per message**, reused across retries. One event matching
  two subscriptions to the same receiver used to share an id, so a deduplicating receiver dropped
  the second. (PR 1669)

## Fixed

- **The events bridge lost events fired while it restarted.** It now unsubscribes each watch with a
  cursor before resubscribing, so the upstream replays from the cursor. (PR 1672)
- **`-32020` data showed a string argument in JSON quotes.** (PR 1668)

Also in this range: the agents conformance suite quotes agents-wg 22 at its merge commit, the
README gains a "Why mcpkit" section and a refreshed conformance table, massrelay moves to v0.3.6
with oneauth v0.3.2 everywhere, and CI cache and dependabot changes (PRs 1657, 1660, 1661, 1662,
1667, 1675).

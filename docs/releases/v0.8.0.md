# v0.8.0

A minor release, mostly events and agents. The events server and Go client now
score green against both SEP-3415 conformance suites, and the same suite has
graded a second implementation, `metronome-mcp.fly.dev`, through a new auth
proxy. The agents extension gained caching, model-role routing, step-up and
`list_changed`, plus a walkthrough and its own conformance scenarios. It also
moved to the identifier the agents SEP defines, which is wire-breaking, so
this is a minor rather than a patch. `golang.org/x/net` moves to v0.60.0 in
every module for GO-2026-6617.

## Upgrading

- **`experimental/ext/agents` advertises `io.modelcontextprotocol/agents`**
  in place of `io.mcpkit/agents`. A host that negotiated the old key no longer
  finds the extension. Hosts using `agents.ExtensionID` follow automatically.
  (PR 1541, #1393)
- **`events/stream` refuses a source that declares no `push`** with
  `-32026 {feature: deliveryMode, value: push}`, as poll and subscribe already
  did for their modes. A source that declares no `delivery` at all still
  derives push from its capability. (PR 1537, #1417)
- **`ext/auth`: a `CallbackPort` that something else holds** now fails before
  a client is registered, where it used to register and then fail to serve.
  (PR 1544, #1539)
- **Go 1.26.9** is the toolchain floor across all modules.

## Security

- **`golang.org/x/net` v0.60.0** in all 49 modules that use it, fixing
  GO-2026-6617 (an HTTP/2 server crash). govulncheck found it reachable from
  `examples/mcpskills-walkthrough`. (PR 1550)

## Added

- **Events: `Registry.ChangeSchema`** replaces an event type's `inputSchema`
  and/or `payloadSchema` in place. The caller says whether the change is
  additive, which keeps every subscription, or breaking, which ends push and
  webhook subscriptions with `-32026 {feature, reason: "schema_changed"}`.
  Either way `list_changed` follows. (PR 1537, #1465)

- **Events: `list_changed` over `subscriptions/listen`.** The server
  registers the `eventsListChanged` filter key and honours it only when it
  declared `listChanged: true`. The Go client gains the listen API, and the
  client conformance suite runs on both lifecycles. (PR 1531, #1505)

- **`ext/auth/cmd/mcp-auth-proxy`** fronts an OAuth-protected MCP server with
  a loopback endpoint that adds the bearer token, logging in headlessly and
  again on any 401. `make conf-events-remote` uses it to grade another
  implementation's events server. (PR 1538, PR 1549, #1535)

- **Agents: `notifications/agents/list_changed`.** The extension declares
  `listChanged: true`, `AddAgent` / `RemoveAgent` broadcast, and
  `NotifyListChanged` covers changes the registry cannot see. (PR 1536, #1393)

- **Agents Go client: `Cache` and `RoleTable`.** `Cache` keeps the roster and
  each agent's details for their `ttlMs`, drops entries on `agent_not_found`,
  and never caches `invalid_agent_definition`. `RoleTable` resolves
  `modelRoutingHint` to a host's own models, escalating rather than
  downgrading. (PR 1536, #1393)

- **Agents: step-up.** `AgentDef.ScopeChallenge` keeps an agent in a caller's
  roster while refusing `agents/get` with a 403 `insufficient_scope` challenge
  until the caller holds the named scopes. `core.InsufficientScopeChallenge`
  builds that header without depending on `ext/auth`. (PR 1540, #1393)

- **`examples/agents/discovery`** walks through the agents extension on both
  wires, and `make testconf-agents` grades it against agents-wg#22 (stage 8k,
  `INFO`). (PR 1540, PR 1545, #1393)

- **Skills: cache attributes on `resources/directory/read`**, `ttlMs` and
  `cacheScope`, as `skills/list` and `skills/get` already carry.
  `WithDirectoryReadCacheHints` overrides the defaults. (PR 1543)

## Changed

- **`ext/auth`: `OAuthTokenSource` binds its callback listener before client
  registration** and hands that socket to oneauth, so the port registered is
  the port served. oneauth is at v0.1.40. (PR 1544, PR 1548, #1539)

## Fixed

- **`make check-release-workflows`** runs its checker under `uv run`, since it
  failed with `ModuleNotFoundError` at the v0.7.2 release step. (PR 1533)

## Tooling

- Events conformance quotes SEP-3415 on every row, with a section link, and
  grades stream-mode refusal, catalog changes, 410 survival, `lastError` and
  a cross-tenant check that can now fail. `make testconf-events` is
  122 / 1 / 12 against kitchen-sink. (PR 1530, PR 1532, PR 1537)
- `testconf-events` and `conf-events-remote` pick a free port when
  `EVENTS_PORT` / `EVENTS_REMOTE_PORT` is unset, so two sessions can run them
  at once. (PR 1549, #1534)
